## What changed this session

### 1. Palette: Apple's dark product pages

Defined in `css/tokens.css` and recorded in the spec table.

| Role | Values |
|---|---|
| Page and image wells | `#000000` |
| Panels and surfaces | `#161617`, `#1d1d1f`, hover `#262628` |
| Text | `#f5f5f7` (main), `#a1a1a6` (muted), `#86868b` (subtle) |
| Accent | `#0071e3` with white text (4.7:1); hover `#0062c4` (5.9:1) |

- **Hover blue:** Apple's own hover `#0077ed` fails AA with white text, so the hover is darker instead.
- **Accent as text:** the accent reaches only 3.9:1 on panels, so it is used for fills and icons only, never for text.
- **Chart greys:** the old warm and slate greys in `light.js` and `tracking.js` were replaced with the same Apple greys.

### 2. Tracker verdict (`/impeccable bolder` + `delight`, then the critique's P0)

- **Headline:** the verdict `#verdict-head` is 24 px / 700, e.g. "Speed within 0.3% of JPL".
- **Sample size:** a `span.verdict-sample` on the next line reads "N of M frames measured". With fewer than 5 measured frames it turns amber and starts with "Low confidence ·".
- **Comparison rows:** `#verdict-compare` lists Measured and JPL side by side, with JPL in `--predict`.
- **Hidden cards:** the Speed and Heading cards are hidden while the comparison shows, because they repeat it.
- **Draw-on:** when a track finishes, the measured trace and JPL's dashed path draw on together over 900 ms (via `pathLength` and a mask), and the headline wipes in. All of this is in `css/overrides.css` and is off under reduced motion.

### 3. Band colours (`/impeccable colorize`)

- **Tokens:** `--d1`…`--d6` (violet to red, short to long wavelength) mirror the existing `hues` in `app.js`.
- **Dot helper:** `.has-swatch` in `tokens.css` draws a dot from `--swatch`.
- **Where the dots appear:**
  - The Band dropdown (via `data-swatch` on the options, which `ui-select.js` reads).
  - The image date badges.
  - A new `.band-legend` under the spectrum chart.

### 4. Critique fixes

Critique score: 22/40. The snapshot is in `.impeccable/critique/`.

- **Busy state:** while a track runs, Track point reads "Tracking…" and Clear reads "Cancel". Cancel is `clear()`, which resets everything.
- **Walkthrough card:** `#vesta-callout` hides when a track starts and returns on Clear or a new pick.
- **Verdict in view:** when a track finishes, the verdict scrolls into view inside the side panel.
- **Object note:** `#track-object-note` reads "Tracks Vesta at its JPL-predicted position, not the pixel you click." This matches `tracking.py:471`.
- **3D Map legend:** now "Cyan → yellow → rose: increasing redshift", which matches `galaxyColor`.
- **3D Map notes:** `text-wrap: pretty` on them, so the last line doesn't end on a single word.
- **Spectrum window option:** now reads "All dates · slow", and choosing it shows a status warning.

### 5. Audit fixes

Audit score: 15/20. The snapshot is in `.impeccable/audit/`. Four parallel agents did this work.

- **Track progress (`server.py`, `create_track`):** the job stage now says "Downloading frames k / N (M already cached)" or "All N frames already cached". The download code itself is unchanged.
- **Announcements:** `#track-status` loses `role=status` while busy. A hidden announcer says only that tracking started, the result, or the failure.
- **Chart text alternatives:** `#track-plot`, `#track-change-plot` and `#light-chart` get text labels built from values the code already computes. All three now use `role="group"`, because they contain focusable points.
- **Filmstrip:** it is now one tab stop with a roving tabindex: arrows, Home and End move focus; Enter or Space opens the frame.
- **Skip links:** "Skip to image" and "Skip to tracker" (`#tracker`), styled in `css/controls.css`.
- **Phones:**
  - The sky and reference canvases use `touch-action: pan-y pinch-zoom`, so a finger can scroll the page over the image.
  - A `touchstart` listener blocks page scrolling only when the image is zoomed in (`state.zoom > 1`).
  - Range sliders are 24 px tall, and 44 px on narrow or coarse-pointer screens.
- **Polish:**
  - `PRED` in `tracking.js` now equals `--predict` (`#b9a3f5`).
  - At 1120 px and narrower, the image toolbar `.viewer-bar` fades at whichever edge has more controls (`css/responsive.css`).

## Known issues and decisions for the user

1. **Cold cache means a long first track.** Today the frame cache had been emptied, and two tracks sat for more than 25 minutes while about 170 files downloaded in 10 minutes. The public server on 8765 shares `work/prototype-cache` (through the `branch1` junction), so the two compete for bandwidth. Progress now shows, but the wait doesn't change. **Before a demo, run one Vesta track on the presenting machine and let it finish.**
2. **Don't demo Measure spectrum on Vesta.** The asteroid moves, so the fixed measurement position lands on empty sky (one point, about −40 µJy). Use a star field.
3. **Stray screenshots.** `legend-1440.png` and `tracker-1440.png` at the repo root were left by an agent. Delete them before committing.
4. **Clear wraps at 375 px.** The Clear button drops onto its own row under Track point.
5. **README is out of date.** `outputs/spherex-prototype/README.md` still says "white as the primary accent". It should describe the blue accent and the band colour scale.
6. **No Impeccable context files.** There is no PRODUCT.md or DESIGN.md, so `/impeccable doctor` has nothing to check. `/impeccable init` or `document` would create them.
7. **Not yet done from the critique and audit:**

   - Plain-language labels for jargon ("Load patch", "Pick 2nd", "Full FOV", "z").
   - Consistent release/band naming (DR1/QR3 vs D1–D6).

## How to run, check and deploy

- **Python:** `work/venv/Scripts/python.exe -X utf8`. The venv itself is empty: `server.py` adds `work/deps` to `sys.path`. Teammates should follow `startguide.md` instead.
- **Dev copy:** from `outputs/spherex-prototype`, run `SPHEREX_CACHE_GB=50 ../../work/venv/Scripts/python.exe -X utf8 server.py --port 8767`. Never develop against 8765. Restart the server after editing `server.py`, and confirm nothing else is listening first: Windows lets two processes bind the same port.
- **Browser:**
  - Use `~/.claude/skills/gstack/browse/dist/browse` with its own `BROWSE_STATE_FILE=<worktree>/work/browse/<task>/browse.json` per agent, and stop sessions when done.
  - Never use `mcp__claude-in-chrome__*`.
  - A fresh browse session has an empty HTTP cache.
- **Timings:** the page needs about 12 s to load. A track on a warm cache takes about 1 minute; on a cold cache, many minutes.
- **Deploy** (only after the user approves):
  1. Commit on `fable`.
  2. In `worktrees/branch1`, run `git merge --ff-only fable`.
  3. Stop the process on 8765 and its launcher, and confirm nothing is listening on 8765.
  4. Start `server.py --port 8765` with `SPHEREX_PUBLIC=1`.
  5. Load the public link and check:
     - every file loads;
     - `tokens.css?v=16` is served;
     - "Frame 18 / 58" appears.
  - Keep `request_queue_size = 64` in `server.py`.
  - The `work` folder in `branch1` is a junction. Remove it with `cmd /c rmdir`, never with a recursive delete.
