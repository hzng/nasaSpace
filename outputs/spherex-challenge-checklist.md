# Planet X and SPHEREx Checklist

## Build the core tool

- [ ] Make the viewer publicly accessible.
- [ ] Let users enter Right Ascension (RA) and declination (Dec) to find real SPHEREx images of a sky patch.
- [ ] Line up images of the same patch and play them in date order. Show the date and let users pause or step through frames to spot changes.

## Try the five challenge targets

- [ ] Barnard’s Star
- [ ] Epsilon Indi B
- [ ] WISE 0855 — RA `08h55m10.831s`, Dec `−07°14′42.53″`
- [ ] RW Aurigae
- [ ] R Draconis

## Optional improvements

- [ ] Make it easy to add new SPHEREx releases.
- [ ] Let users switch infrared bands or combine images from the same detector for a clearer view. For extra credit, generate a brightness-by-band chart (spectrum) when a user selects an object.
- [ ] Let users add or subtract images from different dates to reveal changes.
- [ ] Let users choose the size of the sky patch.
- [ ] Add Gaia or WISE overlays and show image quality flags.
- [ ] Support coordinates in the URL so a sky view can be shared or embedded.
- [ ] Consider Astropy for image processing or Aladin for sky display.
